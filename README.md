## Projetos

### [CryptoChar](https://cryptochar.septiumdigital.com)

RPG 2D em pixel art, jogado no navegador, em que cada herói nasce de uma chave criptográfica, como uma paper wallet do Bitcoin. O jogador forja a chave na bigorna, e o personagem é calculado a partir dela: a mesma chave gera sempre o mesmo herói. Tem multiplayer, treino com chefes e mundo aberto.

O jogo está no ar, mas o código é privado.

### [MicruxSip](https://github.com/ezequieljc/micruxsip)

Softphone SIP para Linux com a cara e o jeito de usar do MicroSIP do Windows, para quem trabalha com ramal em Asterisk, FreePBX, Issabel ou 3CX e migrou de sistema. Tem conferência, gravação, transferência, agenda e várias contas.

### [canivt](https://github.com/ezequieljc/canivt)

Gerenciador de arquivos e editor de texto para o terminal, com barra de favoritos e acesso a servidores Samba. É um único arquivo Python, sem dependências além da biblioteca padrão, e abre instantaneamente.

### [my-debian-setup](https://github.com/ezequieljc/my-debian-setup)

Meu ambiente de trabalho em um único instalador: transforma um Debian 13 com XFCE recém-instalado num desktop com i3, barra em Quickshell e o tema QuielRed. É baseado no [omaxian](https://github.com/aozora/omaxian).
